# KmerHosting Domains v1.3.3

## UI

- Replaces the legacy public footer with the Carbon footer architecture used by `KmerHosting/website`.
- Uses a dedicated Carbon `g100` footer theme so footer contrast remains stable regardless of the current application theme.
- Adds responsive navigation groups and Carbon accordions for smaller screens.
- Adds KmerHosting resource, developer, legal, support and social links while preserving domain-specific navigation.

## Administration

- `admin@kmerhosting.com` is now an active administrator of the Domains platform.

## Preserved behavior

- KmerHosting opaque-session authentication remains unchanged.
- Registrar environment isolation, wallet billing, DNS ownership checks, order guards and administrator safety rules remain intact.

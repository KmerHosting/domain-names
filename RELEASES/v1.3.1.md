# KmerHosting Domains v1.3.1

This maintenance release fixes production theme contrast and authentication gateway regressions introduced around the Carbon rebuild.

## Fixed

- Apply Carbon `g10` / `g90` theme tokens to the rendered application root, not only to React theme context.
- Restore readable foreground/background contrast across legacy marketing, customer, admin and form surfaces in both light and dark themes.
- Fix inverse footer and CTA text/link colors so footer content remains readable in light theme.
- Stop Supabase Edge gateway JWT validation from rejecting the KmerHosting opaque domain session token with `Invalid JWT`.
- Keep protected browser-facing Edge Functions secured by their existing `domain_sessions` / `domain_users` validation, role checks and session-version checks.
- Keep internal cron and provider-worker authentication unchanged.
- Add a canonical `Customer dashboard` link to the administration sidebar, targeting `https://domain.kmerhosting.com/dashboard`.

## Safety

Registrar environment isolation, DomainNameAPI provider guards, customer-credit billing, DNS ownership checks, order guards and administrator continuity protections are unchanged.

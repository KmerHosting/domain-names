# KmerHosting Domains v1.3.2

Hotfix for customer notifications and account navigation.

## Fixed

- Restore the customer notification API used by `/dashboard/notifications`.
- Add `GET /notifications`, `POST /notifications/:id/read` and `POST /notifications/read-all` to `domain-customer-tools`.
- Return an unread notification count directly from the customer tools API.
- Keep the KmerHosting opaque domain session validation and `verify_jwt=false` gateway configuration used by browser-facing domain functions.
- Show `Customer dashboard` in the user account dropdown whenever the user is outside the `/dashboard` area.
- Keep the admin sidebar shortcut to the customer dashboard.

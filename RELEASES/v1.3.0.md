# KmerHosting Domains v1.3.0

Release date: 2026-08-19

## Carbon UI/UX rebuild

- Rebuilt the domain portal around the canonical Carbon application shell used by KmerHosting Dashboard.
- Migrated customer, DNS, lifecycle, provider, and administration screens to official Carbon React components.
- Aligned the application with Carbon g10 light and g90 dark themes, semantic tokens, responsive breakpoints, and productive motion.
- Added Carbon Header, HeaderPanel, SideNav rail, and SkipToContent patterns across customer and admin experiences.
- Removed `lucide-react` from production dependencies.
- Locked the UI migration debt at zero native React control/table usages and zero Lucide import sites.
- Added Carbon source/style and shell-layout audits to CI.

## Business logic

Registrar operations, DomainNameAPI OTE/production isolation, wallet/customer-credit billing, DNS operations, SSO, order guards, and admin safety rules remain preserved.
